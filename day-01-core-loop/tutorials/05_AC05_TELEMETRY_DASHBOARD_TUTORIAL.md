## 🎧 Part 1: The "Why" - Observability Kyun Zaroori Hai?

Peter Drucker ka ek mashhoor quote hai:  
> *"You cannot improve what you cannot measure."*

Agar tumhara agent ek black box hai jisme tumne ek prompt daala aur usne ek text output de diya:
- Tumhe kaise pata chalega ki query mein kitna time laga? (Latency)
- Tumhe kaise pata chalega ki is query par company ke kitne paise kharch hue? (Cost Accounting)
- Tumhe kaise pata chalega ki kitne tokens prompt mein gaye aur kitne completion mein aaye? (Token Distribution)
- Prompt caching kaam kar rahi hai ya nahi? (Cache Read Tokens)

**Real-world Analogy:**  
Jab tum cab (Uber/Ola) lete ho, toh ride khatam hote hi receipt milti hai:  
- Distance: 12 km
- Time: 28 mins
- Base Fare: ₹150
- Tax: ₹25  
- Total: ₹175  

Agar cab driver bas bole *"Pahunch gaye!"* aur koi meter na ho, toh production mein koi us service par bharosa nahi karega!

**AC-05 ka Goal:**  
Har agentic run ke khatam hote hi ek **Clean, Production-Ready Telemetry Dashboard** print hona chahiye jo latency, turn count, exact token breakdown aur financial cost ko transparently dikhaye.

## ⚙️ Part 2: `ResultMessage` ke Telemetry Fields

`ResultMessage` ke andar SDK humein ye saare metadata fields deta hai:

```python
@dataclass
class ResultMessage:
    subtype: str                 # "success", "error_max_budget_usd", etc.
    duration_ms: int             # Total run time in milliseconds
    duration_api_ms: int         # Time spent waiting specifically on API calls
    num_turns: int               # Number of execution turns taken
    total_cost_usd: float | None # Exact calculated cost in USD
    usage: dict[str, Any] | None # Token breakdown dictionary
    result: str | None           # Final assistant text/output
```

### `usage` dictionary ke andar kya milta hai?
```python
{
    "input_tokens": 1420,        # Prompt tokens sent
    "output_tokens": 312,        # Tokens generated by model
    "cache_read_input_tokens": 850,   # Tokens served from Anthropic prompt cache (90% cheaper!)
    "cache_creation_input_tokens": 0  # Tokens newly written to prompt cache
}
```

## 🛠️ Part 3: Production Code Pattern for AC-05

Chalo ek reusable telemetry visualizer function banate hain:

```python
import os
import sys
import asyncio
from dotenv import load_dotenv

if sys.platform == "win32":
    sys.stdout.reconfigure(encoding="utf-8", errors="replace")

load_dotenv()

from claude_agent_sdk import query, ClaudeAgentOptions
from claude_agent_sdk.types import ResultMessage, StreamEvent


def print_telemetry_dashboard(msg: ResultMessage):
    """
    Renders a formatted observability dashboard from a ResultMessage.
    """
    duration_sec = (msg.duration_ms or 0) / 1000
    api_duration_sec = (getattr(msg, "duration_api_ms", 0) or 0) / 1000
    cost = msg.total_cost_usd or 0.0
    usage = getattr(msg, "usage", {}) or {}

    input_tokens = usage.get("input_tokens", 0)
    output_tokens = usage.get("output_tokens", 0)
    cache_read = usage.get("cache_read_input_tokens", 0)

    print("\n" + "╔" + "═" * 58 + "╗")
    print("║" + "           📊 AGENT RUN TELEMETRY REPORT            ".center(58) + "║")
    print("╠" + "═" * 58 + "╣")
    print(f"║  Execution Status   : {msg.subtype:<34} ║")
    print(f"║  Total Turns        : {msg.num_turns:<34} ║")
    print(f"║  Total Duration     : {duration_sec:.2f}s (API: {api_duration_sec:.2f}s)".ljust(58) + " ║")
    print("╟" + "─" * 58 + "╢")
    print("║  TOKEN CONSUMPTION:                                      ║")
    print(f"║    • Input Tokens   : {input_tokens:<34} ║")
    print(f"║    • Output Tokens  : {output_tokens:<34} ║")
    print(f"║    • Cache Read     : {cache_read:<34} ║")
    print("╟" + "─" * 58 + "╢")
    print(f"║  💰 Total Cost (USD): ${cost:.6f}".ljust(58) + " ║")
    print("╚" + "═" * 58 + "╝\n")


async def run_telemetry_demo():
    options = ClaudeAgentOptions(
        model=os.environ.get("ANTHROPIC_MODEL", "claude-sonnet-4-5-20250929"),
        include_partial_messages=True,
        max_turns=2
    )

    prompt = "Explain in 2 sentences why prompt caching reduces LLM cost."
    print(f"👤 User: {prompt}\n")

    async for message in query(prompt=prompt, options=options):
        # Stream text deltas
        if isinstance(message, StreamEvent):
            event = message.event
            if event.get("type") == "content_block_delta":
                delta = event.get("delta", {})
                if delta.get("type") == "text_delta":
                    print(delta.get("text", ""), end="", flush=True)

        # Catch ResultMessage and render dashboard
        elif isinstance(message, ResultMessage):
            print("\n")
            print_telemetry_dashboard(message)


if __name__ == "__main__":
    asyncio.run(run_telemetry_demo())
```

## 💡 Quick Recall Quiz:

1. **Question:** `duration_ms` aur `duration_api_ms` mein kya difference hota hai?  
   **Answer:** `duration_ms` poori script/run ka total time hota hai (including local tool execution), jabki `duration_api_ms` sirf network par model ka response aane ka wait time hota hai.
2. **Question:** `cache_read_input_tokens` badhne se cost par kya asar padta hai?  
   **Answer:** Prompt Caching se repeated system prompts ya long context par cost lagbhag 90% tak kam ho jaati hai!
